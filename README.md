# homebrew-tap

Homebrew casks for my macOS apps.

```bash
brew tap estruyf/tap
```

## [LinkLane](https://github.com/estruyf/LinkLane)

Browser picker that routes every link to the browser you choose. Apple Silicon only.

```bash
brew install --cask estruyf/tap/linklane
```

## [Tideline](https://github.com/estruyf/tideline)

Menu bar app that files older downloads into folders by arrival date. Requires macOS 14 or later.

```bash
brew install --cask estruyf/tap/tideline
```
